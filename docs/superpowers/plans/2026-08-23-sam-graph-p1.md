# SAM Graph P1 Representation Learning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build isolated, train-only Stage 1 SAM node representation, GT prototype, and GT EdgeNet components on top of the P0 shared-mask pipeline.

**Architecture:** New modules under `models/graph/` consume the existing MobileSAM stage3/neck outputs without changing `ChangeDetection`. FP32 region pooling feeds a 128-dimensional temporal projector; GT-only prototype and edge objectives are coordinated independently from the existing training loop.

**Tech Stack:** Python 3.8, PyTorch, NumPy, standard-library unittest; no new dependencies.

## Global Constraints

- Do not modify `ChangeDetection`, `train.py`, validation, inference, or existing checkpoint payloads.
- Use stage3 output index 2 and encoder-neck output index 4; do not use forward hooks.
- Detach backbone features by default.
- Class 0 is never a prototype, graph prediction, queue entry, or edge target.
- Use FP32 for pooling, normalization, cosine logits, and EdgeNet BCE.
- Empty inputs and absent pairs must produce finite graph-connected zero losses.
- P1 excludes GAT, unlabeled propagation, temporal KL, pixel projection, teacher veto, and pseudo labels.
